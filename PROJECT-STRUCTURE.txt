WaterServe source layout

Start: app/page.tsx
Application state and actions: hooks/useWaterServe.ts
Resident screens: components/resident/
Staff screens: components/staff/
Authentication screens: components/auth/
Shared interface elements: components/shared/
Incident table and details: components/incidents/
Header and footer: components/layout/
Client requests, constants, types, and CSV export: lib/
API feature handlers and shared server helpers: lib/server/
Styles: styles/ (imported by app/globals.css)
Database schema: db/
Existing migrations: drizzle/
Development helpers: scripts/
Server entry point: worker/index.ts

Read docs/CODE-GUIDE.md for the folder map and report flow.
Existing database users: keep .wrangler/ and .dev.vars when replacing source files.
